## 形态一：年付摊薄，2 美元档里配置最实在的一类

把年付总价除以 12 得到的月价，是目前 $2 档最主流的玩法，也是最值得买的一种。

社区优惠汇总在 2026 年 10 月更新的记录里有几台典型机器：RackNerd 的 1.5GB KVM 是 1 核、1.5GB 内存、30GB SSD RAID-10、3TB 月流量，**$16.88/年**，折合 $1.41/月；同系列 2GB 是 2 核、25GB SSD、4TB 流量，**$20.98/年**，折合 $1.75/月。Server Host 的 2GB 是 $21.88/年，CloudServer 的 2GB 是 $23.88/年，DediRock 的 2GB 是 $20.88/年。

这一档的共同点是 KVM 虚拟化、独立 IPv4、完整 root、SolusVM 面板自助重装。KVM 的内存和磁盘是硬分配，1GB 就是 1GB，重启行为和真机一致，不像 OpenVZ 那样和宿主机池化共享。

需要提醒的是，这类社区优惠常有下架，链接点进去发现售罄是正常的，价格以商家结算页为准。

## 形态二：NAT 共享 IP，2 美元买一年，但只有 128MB

还有一类机器把公网 IP 也省了：多个用户共享一个公网 IPv4，靠端口映射区分。价格能压到 2 美元一年。

一位第三方作者的记录里，某欧洲机房 NAT 套餐是 128MB 内存、3GB 硬盘、125GB 月流量，年付 2 美元，SSH 走邮件下发的高位端口，Web 服务给大约 20 个可用端口，作者判断硬件是七八年前的机器。这类记录来自个人博客、非官方，只能当形态举例。

要用它对外提供服务，基本得绕开端口限制：Nginx 反代统一入口、Cloudflare Tunnel 穿透（不需要端口映射）、开 IPv6 拿独立公网地址直连、frp 自建中转、ZeroTier 组网。同一篇记录提到，早期机型带每周快照，后来买的和迁移过的机型已经没有备份功能。

128MB 内存能干什么：跑一个静态站、一个轻量 API、一台 WireGuard，或者纯当 Linux 练习机。装 WordPress 会很勉强。它是学习工具，不是建站方案。

## 容易被忽略的四个限制

**超售是常态。** 这个价位多租户共享底层硬件，同一节点上邻居跑满，你的磁盘 IO 和网络就会抖。挑有社区口碑的老商家，比挑参数好看的便宜货更划算。

**CPU 是共享的，不是独享。** KVM 下内存和磁盘硬分配，CPU 只保证公平份额。节点空闲时能 burst 到很高，晚高峰大家都忙的时候只能拿到自己那一份。跑编译、转码这类吃满 CPU 的任务，体验落差明显。

**备份基本没有。** JustHost 官方明确不提供自动备份，低价年付机多数也不带快照。数据要么放 Git，要么自己定时 rsync 到另一台机器。

**只能升配，不能降档。** 这类套餐升级通常需要重启，一分钟内完成，按比例补差价；降档一般不支持。不确定就从小配置买起。

## 按场景选：什么用途配什么档

**静态博客、作品集（Hugo、Jekyll、Ghost）**：512MB 到 1GB 足够，年付促销机是性价比最高的选择。JustHost 的 Sirius 是 1 核 1GB，跑静态站属于浪费，但换机房方便，适合面向多地区读者的站。

**WordPress 小站**：512MB 是跑 WordPress 加基础插件与缓存方案的下限，插件一多就会 OOM，1GB 更稳。这个价位不适合有流量峰值的站。

**Telegram / Discord 机器人**：512MB 内存、1 核足够，Python 或 Node.js 脚本随便跑。选机房时挑离 API 服务器近的。

**个人 VPN（WireGuard / OpenVPN）**：1 核 512MB 能跑，瓶颈在流量和线路，不在配置。要回国线路就别看这个价位了。

**学 Linux、测试环境**：最低配就行，随便折腾，重装系统在面板里点一下。

**数据库、需要持续并发的生产服务**：2 美元档全部不适合，直接上 2GB 或更高。

判断自己该选哪一档有个简单算法：现在跑在 $5 云主机上的东西，如果长期用不到一半资源，1GB 的廉价机基本能干同样的活，价格是三分之一；如果那台机器经常打满，就该上 2GB 档。
